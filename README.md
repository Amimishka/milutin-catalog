# Михаил Милютин — демонстрационный каталог

React-прототип авторской ювелирной витрины и редактора карточек.

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес, показанный Vite. Витрина находится на `/`, демонстрационный редактор — на `/editor`. Продакшн-сборка: `npm run build`, локальный просмотр сборки: `npm run preview`.

Редактор сохраняет добавленные карточки и загруженные изображения в localStorage текущего браузера. Данные не синхронизируются между устройствами; объём зависит от лимита браузера. Любую карточку можно удалить из витрины. Удаление исходной коллекции скрывает её в текущем браузере; кнопка сброса возвращает исходные коллекции и удаляет добавленные демо-карточки. Исходные записи находятся в `catalog-data.json`; соответствие фотографиям задано в `src/main.jsx`. Для настоящей публикации и работы нескольких пользователей потребуется серверное хранилище и авторизация. Для подключения почты задайте адрес ателье в переменной Vite `VITE_ATELIER_EMAIL` перед сборкой. Пока адрес не указан, кнопка связи поясняет демонстрационный режим.
