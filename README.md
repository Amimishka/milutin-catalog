# Михаил Милютин — демонстрационный каталог

React-прототип авторской ювелирной витрины и редактора карточек.

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес, показанный Vite. Витрина находится на `/`, демонстрационный редактор — на `/editor`. Продакшн-сборка: `npm run build`, локальный просмотр сборки: `npm run preview`.

Редактор сохраняет добавленные карточки и загруженные изображения в localStorage текущего браузера. Данные не синхронизируются между устройствами; объём зависит от лимита браузера. Сброс удаляет только добавленные демо-карточки. Исходные записи остаются в `catalog-data.json`; соответствие фотографиям задано в `src/main.jsx`. Для настоящей публикации и работы нескольких пользователей потребуется серверное хранилище и авторизация. Адрес для связи `atelier@example.com` — демонстрационный, его нужно заменить настоящим.
