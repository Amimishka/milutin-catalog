# Milutin Catalogue — handoff

В папке лежат:

- `reference/` — визуальный ориентир для первого экрана;
- `product-images/` — исходные предметные фотографии: их холодный серый фон нельзя заменять;
- `assets/` — оригинальные декоративные ассеты для hero-экрана;
- `catalog-data.json` — стартовая привязка коллекций к шаблонам.

## Требование к реализации

Собрать на JavaScript + React + Bootstrap адаптивный каталог. Django/CMS на
этой стадии не подключать. Насыщенная каменная архитектура и витражи должны
быть только в hero; каталог ниже — заметно спокойнее.

Разрешены только три шаблона карточек: `arch`, `portrait`, `wide`. Ни
исходные фото, ни фон на них не перерисовывать, не заменять и не переносить на
бархат, мрамор, цветы или кремовую подложку.

На desktop первый экран показывает арку, витражи и колье. На mobile остаются
арка и колье, но боковой декор упрощается; каталог становится одной колонкой
без горизонтальной прокрутки.
